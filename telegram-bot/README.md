# 🏛 Telegram-бот «Империя»

Telegram-бот для ресторана высокой кухни **«Империя»**, написан на Python с использованием библиотеки [python-telegram-bot v20](https://github.com/python-telegram-bot/python-telegram-bot).

## Возможности

- 👋 Приветственное сообщение при первом запуске (`/start`)
- 📋 Интерактивное меню с категориями (Закуски, Супы, Главные блюда, Десерты, Напитки)
- 📅 Пошаговое бронирование стола (имя → дата → количество гостей → телефон)
- ℹ️ Информация о ресторане (адрес, часы работы, телефон)
- 🔔 Уведомление администратора о новых бронированиях (опционально)
- 🎛 Inline-кнопки для навигации по всему боту

## Структура проекта

```
telegram-bot-imperiya/
├── bot.py          # Точка входа; все обработчики и сборка приложения
├── keyboards.py    # Фабрики inline-клавиатур
├── menu_data.py    # Данные меню (блюда, цены, описания)
├── requirements.txt
├── .env.example
└── .gitignore
```

## Запуск

### 1. Получить токен бота

Напишите [@BotFather](https://t.me/BotFather) в Telegram, создайте бота командой `/newbot` и скопируйте токен.

### 2. Установить зависимости

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настроить переменные окружения

```bash
cp .env.example .env
# Откройте .env и вставьте ваш BOT_TOKEN
```

Опционально: укажите `ADMIN_CHAT_ID` — ваш Telegram ID — и все заявки на бронирование будут пересылаться вам. Узнать свой ID можно у [@userinfobot](https://t.me/userinfobot).

### 4. Запустить

```bash
python bot.py
```

## Команды бота

| Команда   | Описание                        |
|-----------|---------------------------------|
| `/start`  | Открыть главное меню            |
| `/cancel` | Отменить текущее бронирование   |

## Добавление блюд

Откройте `menu_data.py` и добавьте новые позиции в нужную категорию:

```python
{
    "name": "Название блюда",
    "price": "X XXX ₽",
    "desc": "Краткое описание",
},
```
